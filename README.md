# QR AI 🚀

A modern, high-performance Flutter application designed for seamless QR code scanning, code generation, and intelligent analysis powered by Google Gemini AI.

---

## ✨ Features

- **⚡ Fast QR & Barcode Scanning:** Powered by `mobile_scanner` for lightning-fast and accurate code detection.
- **🛠️ Custom QR Generator:** Easily create your own QR codes using `qr_flutter`.
- **🤖 AI-Powered Analysis:** Intelligent processing and integration with Google Generative AI (Gemini).
- **💾 Local History Management:** Saves your scan and generation history securely using Hive database.
- **🔗 Smart Utilities:** Open scanned links instantly with `url_launcher`, pick images from the gallery, and enjoy a smooth UI with custom loaders (`flutter_spinkit`).

---

## 🛠️ Tech Stack & Packages

- **Framework:** Flutter (Dart)
- **Scanning:** `mobile_scanner`
- **QR Generation:** `qr_flutter`
- **AI Integration:** `google_generative_ai`
- **Local Database:** `hive` & `hive_flutter`
- **Utilities:** `url_launcher`, `image_picker`, `shared_preferences`
